snarkVM now develops on the [`staging`](https://github.com/aleo-labs-protocol/snarkVM/tree/staging) branch and makes each release on a `release/vX.Y` branch. See [BRANCHING_AND_RELEASING.md](https://github.com/aleo-labs-protocol/snarkVM/blob/staging/BRANCHING_AND_RELEASING.md).

To build what runs on testnet, check out the newest tag on the [releases page](https://github.com/aleo-labs-protocol/snarkVM/releases), including pre-releases.
